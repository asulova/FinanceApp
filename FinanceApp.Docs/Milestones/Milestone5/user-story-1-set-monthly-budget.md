# User Story 1: Set Spending Budget

**As a** user,
**I want to** set a spending budget for a period of time,
**so that** I can control my overall expenses.

## Acceptance Criteria
- User can create a budget for a specific period (e.g., monthly, weekly)
- User can specify the budget amount
- Budget is saved and visible in the app
