# Milestone 5

This folder will contain documentation and planning for the Budget Planning functionality in FinanceApp.

## User Stories

1. As a user, I want to set a monthly budget for each spending category so I can control my expenses.
2. As a user, I want to view my budget vs actual spending for each category so I can track my progress.
3. As a user, I want to receive notifications when I am close to exceeding my budget in any category.
4. As a user, I want to edit or delete my budgets for any category.
5. As a user, I want to see a summary of all my budgets and spending on the dashboard.
